## Структура репозиторію

* task3_swap_minmax.cpp — обмін місцями найбільшого та найменшого елементів масиву різних випадкових чисел
* task4_count_greater.cpp — підрахунок кількості елементів масиву, більших за задане число A
* task5_second_largest.cpp — пошук другого за величиною елемента в масиві різних випадкових чисел
* task6_first_zero.cpp — пошук першого нульового елемента масиву або виведення повідомлення про його відсутність

## Компіляція та запуск

`bash

./task3_swap_minmax

g++ task4_count_greater.cpp -o task4_count_greater
./task4_count_greater

g++ task5_second_largest.cpp -o task5_second_largest
./task5_second_largest

g++ task6_first_zero.cpp -o task6_first_zero
./task6_first_zero
